Overview

What does Agent-CWE measure?

Agent-CWE focuses on repository-level vulnerability function localization. A model must reason over repository context and identify the functions that are causally relevant to a security issue, rather than merely returning every function changed by a patch.

01

Repository-level context

Evaluation is designed around realistic repository evidence instead of isolated code snippets.

02

Function-level gold

The target is a precise set of security-relevant functions, suitable for exact-match and retrieval-style evaluation.

03

Independent curation

Multiple independent curation signals can be combined using strict consensus to improve precision.

04

Agent-oriented protocol

The benchmark is intended for code agents that can inspect files, trace calls, and reason over project structure.
